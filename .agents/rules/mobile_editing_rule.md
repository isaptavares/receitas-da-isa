# Regra de Edição Mobile-Only

- **NUNCA** edite o layout/estilos/seção Desktop a menos que a usuária peça explicitamente.
- **TODAS** as edições e alterações devem ser focadas exclusivamente na versão **Mobile** (`@media (max-width: ...)` ou elementos específicos do mobile).
- Se houver qualquer dúvida se a alteração afeta a versão Desktop, **NÃO edite o Desktop** e pergunte antes à usuária.
